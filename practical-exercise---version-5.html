    13.3.2. The entities

    The entities are the objects exchanged between the application's layers. Three of them come from version 4 and are reused without any modification:

    • the exception [ExceptionImpots];
    • the [readonly] class [TaxAdminData] holding the tax administration's data, built by its static methods [fromJsonFile] and [fromArray];

    We add a fourth one, the [Database] entity, which describes the database.

    13.3.2.1. Why no [BaseEntity] base class?

    At this point the PHP 7 course introduced a parent class [BaseEntity] from which all the entities derived. It relied on a rule: an entity's attributes have the same names as the keys of the JSON file it encapsulates. [BaseEntity] could then initialize any entity from a JSON file or an associative array with the loop:

    1
2
3
    foreach ($arrayOfAttributes as $key => $value) {
  $this->$key = $value;
}

    The entities' attributes were declared [protected] (untyped) so that the parent class could modify them, and each entity added its getters and setters. We do not reuse this solution:

    • the loop above silently creates a dynamic attribute when a key in the JSON file is misspelled. This has been deprecated since PHP 8.2, and is forbidden for [readonly] classes;
    • the entities could be modified by any layer, through their setters or the [setFromArrayOfAttributes] method. Our entities are immutable: a layer cannot accidentally modify an object it has received from another;
    • the rule "same names in the JSON and in the class" is still ours, but PHP 8 exploits it directly: the expression [new self(...$tableau)] turns the array's keys into named arguments of the constructor (PHP 8.1). PHP then checks that no key is missing, that none is unknown and that each value has the right type. There is no longer any common code to factor out into a parent class.

    Finally, version 4 already gave the [TaxAdminData] class the [fromArray] method. We will see that it is enough to build a [TaxAdminData] object from the data read from the database. An important consequence is that the [métier] layer of version 4 will be reused without modification: in the PHP 7 course, changing the entities had forced changes to the [métier] layer.

declare(strict_types=1);

// espace de noms
namespace Application;

// une classe de fonctions utilitaires : elle n'est ni instanciable, ni dérivable
final class Utilitaires
{
    // constructeur privé : la classe ne peut être instanciée
    private function __construct()
    {
    }

    // lit un fichier JSON et rend son contenu décodé (les objets JSON deviennent des tableaux associatifs)
    public static function lireFichierJson(string $fileName): mixed
    {
        // on récupère le contenu du fichier
        $contenu = is_readable($fileName) ? file_get_contents($fileName) : false;
        if ($contenu === false) {
            throw new ExceptionImpots("Le fichier [$fileName] n'existe pas ou ne peut être lu", 15);
        }
        // on décode le JSON
        try {
            return json_decode($contenu, true, flags: JSON_THROW_ON_ERROR);
        } catch (\JsonException $ex) {
            throw new ExceptionImpots("Le fichier [$fileName] ne contient pas du JSON valide ({$ex->getMessage()})", 16, $ex);
        }
    }

    // enregistre une valeur au format JSON dans un fichier texte (créé s'il n'existe pas, écrasé sinon)
    public static function écrireFichierJson(string $fileName, mixed $data): void
    {
        // JSON indenté, caractères accentués non échappés, réels toujours écrits avec un point décimal (0.0)

    public function getTaxPayersData(string $taxPayersFilename, string $errorsFilename): array
    {

        // peut lancer une exception [ExceptionImpots]
        $contribuables = Utilitaires::lireFichierJson($taxPayersFilename);

            throw new ExceptionImpots("Le fichier [$taxPayersFilename] ne contient pas un tableau JSON", 17);
        }
        // tableau des données contribuables
        $taxPayersData = [];
        // tableau des erreurs
        $errors = [];
        // on vérifie chacun des contribuables
        foreach ($contribuables as $numéro => $contribuable) {
            $erreurs = $this->check($contribuable);
            if ($erreurs === []) {
                // un contribuable de plus
                $taxPayersData[] = new TaxPayerData(
                    strtolower(trim($contribuable["marié"])),
                    (int) $contribuable["enfants"],
                    (int) $contribuable["salaire"]
                );
            } else {
                // une erreur de plus : on note le numéro du contribuable erroné dans le tableau JSON
                $errors[] = ["numéro" => $numéro, "erreurs" => $erreurs];
            }
        }
        // on enregistre les erreurs dans un fichier JSON
        Utilitaires::écrireFichierJson($errorsFilename, $errors);
        // résultat de la fonction
        return $taxPayersData;

    private function check(mixed $contribuable): array
    {
        // le contribuable doit être un objet JSON
        if (!is_array($contribuable)) {
            return [["contribuable" => $contribuable]];
        }
        $erreurs = [];
        // le statut marital doit être oui ou non
        $marié = $contribuable["marié"] ?? null;
        if (!is_string($marié) || !in_array(strtolower(trim($marié)), ["oui", "non"], true)) {
            $erreurs[] = ["marié" => $marié];
        }
        // le nombre d'enfants et le salaire doivent être des entiers positifs ou nuls
        // donnés sous la forme d'un nombre (2) ou d'une chaîne ("2")
        foreach (["enfants", "salaire"] as $clé) {
            $valeur = $contribuable[$clé] ?? null;
            $valide = (is_int($valeur) && $valeur >= 0)
                || (is_string($valeur) && preg_match('/^\s*\d+\s*$/', $valeur) === 1);
            if (!$valide) {
                $erreurs[] = [$clé => $valeur];
            }
        }
        return $erreurs;
