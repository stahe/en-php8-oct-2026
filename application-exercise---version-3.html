    8. Application exercise – version 3

    We return to the exercise already studied previously (versions 1 and 2) in order to solve it with PHP code using classes. We are going to put into practice what we learned in the three previous chapters:

    • a [readonly] (immutable) class to represent the tax administration data;
    • an interface, an abstract class that partially implements it and a derived class that completes it;
    • a single exception type, [ExceptionImpots], to report all the application's errors;
    • the [#[\Override]] attribute on all methods that implement an interface method or override a parent method.

    Comments

    • line 6: the [ExceptionImpots] class is in the [Application] namespace. All the classes and interfaces of the tax calculation application will be in this namespace;
    • line 9: the [ExceptionImpots] class extends PHP's predefined [RuntimeException] class. As we saw in the chapter on exceptions, an exception is useful first of all through its type: it is the type that lets you catch it with a [catch (ExceptionImpots $ex)] clause;
    • lines 11-12: the PHP 7 course defined a constructor [__construct(string $message, int $code = 0)] that merely called the parent class's constructor. It is useless: the class inherits the constructor of [RuntimeException], which accepts a message, an error code and an optional previous exception. This last parameter will let us wrap a low-level exception (a [JsonException], for example) in an [ExceptionImpots].

    <?php

declare(strict_types=1);

// espace de noms
namespace Application;

// les données de l'administration fiscale : un objet immuable
final readonly class TaxAdminData
{
    // les noms des tableaux et des constantes attendus dans les données
    private const array TABLEAUX = ["limites", "coeffR", "coeffN"];
    private const array CONSTANTES = [
        "plafondQfDemiPart",
        "plafondRevenusCelibatairePourReduction",
        "plafondRevenusCouplePourReduction",
        "valeurReducDemiPart",
        "plafondDecoteCelibataire",
        "plafondDecoteCouple",
        "plafondImpotCouplePourDecote",
        "plafondImpotCelibatairePourDecote",
        "abattementDixPourcentMax",
        "abattementDixPourcentMin",
    ];

    // constructeur privé : on passe obligatoirement par les méthodes [from...]
    private function __construct(
        // tranches d'impôt
        public array $limites,
        public array $coeffR,
        public array $coeffN,
        // constantes de calcul de l'impôt
        public float $plafondQfDemiPart,
        public float $plafondRevenusCelibatairePourReduction,
        public float $plafondRevenusCouplePourReduction,
        public float $valeurReducDemiPart,
        public float $plafondDecoteCelibataire,
        public float $plafondDecoteCouple,
        public float $plafondImpotCouplePourDecote,
        public float $plafondImpotCelibatairePourDecote,
        public float $abattementDixPourcentMax,
        public float $abattementDixPourcentMin,
    ) {
    }

    // construction à partir d'un fichier JSON
    public static function fromJsonFile(string $taxAdminDataFilename): self
    {
        // on récupère le contenu du fichier des données fiscales
        $fileContents = is_readable($taxAdminDataFilename) ? file_get_contents($taxAdminDataFilename) : false;
        // erreur ?
        if ($fileContents === false) {
            throw new ExceptionImpots("Le fichier des données [$taxAdminDataFilename] n'existe pas", 1);
        }
        // on décode le JSON dans un tableau associatif
        try {
            $data = json_decode($fileContents, true, flags: JSON_THROW_ON_ERROR);
        } catch (\JsonException $ex) {
            throw new ExceptionImpots("Le fichier de données JSON [$taxAdminDataFilename] n'a pu être exploité correctement", 2, $ex);
        }
        // le JSON doit être un objet {...}
        if (!is_array($data)) {
            throw new ExceptionImpots("Le fichier de données JSON [$taxAdminDataFilename] ne contient pas un objet JSON", 3);
        }
        // construction de l'objet à partir du tableau associatif
        return self::fromArray($data);
    }

    // construction à partir d'un tableau associatif [nom => valeur]
    public static function fromArray(array $data): self
    {
        // les clés présentes doivent être exactement celles attendues
        $attendues = [...self::TABLEAUX, ...self::CONSTANTES];
        $manquante = array_first(array_diff($attendues, array_keys($data)));
        if ($manquante !== null) {
            throw new ExceptionImpots("L'attribut [$manquante] de [TaxAdminData] n'a pas été initialisé", 4);
        }
        $inconnue = array_first(array_diff(array_keys($data), $attendues));
        if ($inconnue !== null) {
            throw new ExceptionImpots("L'attribut [$inconnue] n'existe pas dans [TaxAdminData]", 5);
        }
        // on vérifie et on convertit chaque valeur
        $valeurs = [];
        foreach (self::TABLEAUX as $clé) {
            // un tableau non vide de réels >= 0
            if (!is_array($data[$clé]) || !array_is_list($data[$clé]) || count($data[$clé]) === 0) {
                throw new ExceptionImpots("La valeur de l'attribut [$clé] est invalide", 6);
            }
            $valeurs[$clé] = array_map(fn(mixed $valeur): float => self::check($clé, $valeur), $data[$clé]);
        }
        // les trois tableaux doivent avoir la même taille
        $taille = count($valeurs["limites"]);
        if (count($valeurs["coeffR"]) !== $taille || count($valeurs["coeffN"]) !== $taille) {
            throw new ExceptionImpots("Les tableaux [limites, coeffR, coeffN] n'ont pas la même taille", 7);
        }
        foreach (self::CONSTANTES as $clé) {
            // un réel >= 0
            $valeurs[$clé] = self::check($clé, $data[$clé]);
        }
        // construction de l'objet : les clés du tableau deviennent des arguments nommés
        return new self(...$valeurs);
    }

    // vérifie qu'une valeur est un nombre réel positif ou nul et le rend sous forme de [float]
    private static function check(string $clé, mixed $value): float
    {
        // on accepte 1551, 1551.78, "1551" mais pas "xx", true, null, -3...
        if ((is_int($value) || is_float($value) || (is_string($value) && is_numeric($value)))
            && (float) $value >= 0) {
            return (float) $value;
        }
        throw new ExceptionImpots("La valeur de l'attribut [$clé] est invalide", 6);
    }

    // chaîne JSON de l'objet
    public function __toString(): string
    {
        return json_encode(get_object_vars($this), JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR);
    }
}

    Comments

    • line 9: the class is [readonly]: all its properties are read-only. Once constructed, a [TaxAdminData] object can no longer be modified: it can be shared safely among all parts of the application. It is also [final]: it cannot be extended;
    • lines 12-24: two private class constants gather the names of the properties expected in the data. Since PHP 8.3, a class constant can be typed (here [array]);
    • lines 27-43: the constructor uses parameter promotion: each parameter becomes a public property with the same name and the same type. The properties have the names of the JSON file's keys. This is an important point that greatly simplifies writing the code, as we will see. The tax brackets are arrays ([array]), the calculation constants are reals ([float]). In PHP 7, properties could not be typed (the PHP 7 course regretted this): they can be since PHP 7.4;
    • line 27: the constructor is private: you cannot write [new TaxAdminData(...)] outside the class. A [TaxAdminData] object can only be obtained through the static methods [fromJsonFile] and [fromArray], which check the validity of the data. We are thus assured that every [TaxAdminData] object contains valid data. In PHP, a class can have only one constructor. Static methods that build an object, sometimes called "named constructors", provide several ways of building an object. The PHP 7 course used instance methods [setFromJsonFile] called on an empty object: [(new TaxAdminData())->setFromJsonFile(...)]. This is impossible with an immutable object;
    • lines 47-67: the [fromJsonFile] method builds a [TaxAdminData] object from the JSON file whose name is passed to it. Its return type [self] designates the class itself;
    • lines 50-53: we read the content of the file. If this is not possible, we throw an [ExceptionImpots] exception. It will propagate up to the main script;
    • lines 56-60: we decode the JSON content of the file. With the [JSON_THROW_ON_ERROR] option (PHP 7.3), the [json_decode] function throws a [JsonException] exception when the JSON is invalid, instead of silently returning [null]. Note the named argument [flags:], which avoids giving a value to the third parameter [depth] of [json_decode]. The [JsonException] exception is wrapped in an [ExceptionImpots]: the calling code has only one exception type to handle but can retrieve the original cause with [$ex->getPrevious()];
    • lines 62-64: a file containing, for example, only the number 12 is valid JSON: we must check that we did get an array;
    • line 66: the rest of the work is delegated to the [fromArray] method. This method is public: it can be used in a later version where the tax administration data will come from a database;
    • lines 73-81: we check that the keys of the [$data] array are exactly the expected names. [[...self::TABLEAUX, ...self::CONSTANTES]] creates an array containing the elements of both arrays. The [array_diff] function returns the elements of the first array that are absent from the second, and the [array_first] function (PHP 8.5) the first element of an array, or [null] if the array is empty. We thus detect a missing key and then an unknown key. This is the most frequent error: a typo in a property name in the [taxadmindata.json] file. In the PHP 7 course, the loop [$this->$key = $value] silently created a dynamic property bearing the wrong name. Since PHP 8.2, the creation of dynamic properties is deprecated, and it is forbidden in a [readonly] class;
    • lines 84-90: each of the three arrays must be a non-empty list ([array_is_list] function, PHP 8.1) all of whose elements are non-negative reals. The [array_map] function applies the [check] method to each of the elements;
    • lines 92-95: the three tax bracket arrays must have the same size;
    • lines 96-99: each of the calculation constants must be a non-negative real;
    • line 101: the [$valeurs] array has as keys the names of the constructor's parameters. The [...] operator applied to an array with string keys turns each element into a named argument (PHP 8.1): this line is equivalent to [new self(limites: $valeurs["limites"], coeffR: $valeurs["coeffR"], ...)]. This is where the choice of identical names for the JSON keys and the class properties simplifies the code;
    • lines 105-113: the [check] method checks that a value [$value] of unknown type ([mixed]) is a non-negative number. Depending on what is written in the JSON file, the value read may be an integer (1551), a real (1551.78), a string convertible to a number ("1551"), a non-convertible string ("xx"), a boolean... The [is_numeric] function returns [true] for a string representing a number. The PHP 7 course performed this check with a regular expression and returned a [stdClass] object indicating whether there had been an error. Here, an error causes an exception and the method simply returns the number as a [float];
    • line 116: the [__toString] method returns the JSON string of the object's properties. The [get_object_vars] function returns an associative array [property name => value].

    8.3.1. Why are there no more getters and setters?

    The PHP 7 course declared the properties private and wrote a getter and a setter for each of them (26 methods), generated automatically by the NetBeans IDE. The setters were "fluent": they returned the [$this] object, which made it possible to chain calls [$data->setLimites($limites)->setCoeffR($coeffR)].

    With PHP 8, this code no longer has any reason to exist:

    • getters were used to read private properties. [readonly] properties can safely be public since they cannot be modified: we write [$taxAdminData->plafondQfDemiPart] instead of [$taxAdminData->getPlafondQfDemiPart()];
    • setters were used to initialize the object and allowed values to be checked. An immutable object is initialized once and for all by its constructor, and the checking is done by the [fromJsonFile] and [fromArray] methods;
    • typed properties guarantee the type of values. The PHP 7 course noted that the statement [$this->plafondQfDemiPart = 'abcd'] was possible: with a [float] property and [declare(strict_types=1)], it causes a [TypeError] error.

    public function calculerImpot(string $marié, int $enfants, int $salaire): array
    {
        // $marié : oui, non
        // $enfants : nombre d'enfants
        // $salaire : salaire annuel
        // $this->taxAdminData : données de l'administration fiscale
        //
        // on récupère les données de l'administration fiscale si ce n'est déjà fait
        $this->taxAdminData ??= $this->getTaxAdminData();
        // calcul de l'impôt avec enfants
        $result1 = $this->calculerImpot2($marié, $enfants, $salaire);
        $impot1 = $result1["impôt"];
        // calcul de l'impôt sans les enfants
        if ($enfants !== 0) {
            $result2 = $this->calculerImpot2($marié, 0, $salaire);
            $impot2 = $result2["impôt"];
            // application du plafonnement du quotient familial
            $plafondDemiPart = $this->taxAdminData->plafondQfDemiPart;
            if ($enfants < 3) {
                // plafondQfDemiPart euros pour les 2 premiers enfants
                $impot2 = $impot2 - $enfants * $plafondDemiPart;
            } else {
                // plafondQfDemiPart euros pour les 2 premiers enfants, le double pour les suivants
                $impot2 = $impot2 - 2 * $plafondDemiPart - ($enfants - 2) * 2 * $plafondDemiPart;
            }
        } else {
            $impot2 = $impot1;
            $result2 = $result1;
        }
        // on prend l'impôt le plus fort avec le taux et la surcôte qui vont avec
        if ($impot1 > $impot2) {
            $impot = $impot1;
            $taux = $result1["taux"];
            $surcôte = $result1["surcôte"];
        } else {
            $surcôte = $impot2 - $impot1 + $result2["surcôte"];
            $impot = $impot2;
            $taux = $result2["taux"];
        }
        // calcul d'une éventuelle décôte
        $décôte = $this->getDecote($marié, $salaire, $impot);
        $impot -= $décôte;
        // calcul d'une éventuelle réduction d'impôts
        $réduction = $this->getRéduction($marié, $salaire, $enfants, $impot);
        $impot -= $réduction;
        // résultat
        return [
            "impôt" => (int) floor($impot),
            "surcôte" => (int) $surcôte,
            "décôte" => (int) $décôte,
            "réduction" => (int) $réduction,
            "taux" => $taux,
        ];
    }

    private function calculerImpot2(string $marié, int $enfants, float $salaire): array
    {
        // nombre de parts
        $nbParts = match ($marié) {
            "oui" => $enfants / 2 + 2,
            "non" => $enfants / 2 + 1,
        };
        // 1 part par enfant à partir du 3e
        if ($enfants >= 3) {
            // une demi-part de + pour chaque enfant à partir du 3e
            $nbParts += 0.5 * ($enfants - 2);
        }
        // revenu imposable
        $revenuImposable = $this->getRevenuImposable($salaire);
        // surcôte
        $surcôte = floor($revenuImposable - 0.9 * $salaire);
        // pour des pbs d'arrondi
        if ($surcôte < 0) {
            $surcôte = 0;
        }
        // quotient familial
        $quotient = $revenuImposable / $nbParts;
        // les tranches d'imposition (des copies des tableaux de l'objet)
        $limites = $this->taxAdminData->limites;
        $coeffR = $this->taxAdminData->coeffR;
        $coeffN = $this->taxAdminData->coeffN;
        // est mis à la fin du tableau limites pour arrêter la boucle qui suit
        $limites[count($limites) - 1] = $quotient;
        // calcul de l'impôt
        $i = 0;
        while ($quotient > $limites[$i]) {
            $i++;
        }
        // maintenant on peut calculer l'impôt
        $impôt = floor($revenuImposable * $coeffR[$i] - $nbParts * $coeffN[$i]);
        // résultat
        return ["impôt" => $impôt, "surcôte" => $surcôte, "taux" => $coeffR[$i]];
    }

    // revenuImposable=salaireAnnuel-abattement
    // l'abattement a un min et un max
    private function getRevenuImposable(float $salaire): float
    {
        // abattement de 10% du salaire, borné par un minimum et un maximum
        $abattement = 0.1 * $salaire;
        $abattement = min($abattement, $this->taxAdminData->abattementDixPourcentMax);
        $abattement = max($abattement, $this->taxAdminData->abattementDixPourcentMin);
        // revenu imposable
        $revenuImposable = $salaire - $abattement;
        // résultat
        return floor($revenuImposable);
    }

    // calcule une décôte éventuelle
    private function getDecote(string $marié, float $salaire, float $impots): float
    {
        // au départ, une décôte nulle
        $décôte = 0;
        // montant maximal d'impôt pour avoir la décôte
        $plafondImpôtPourDécôte = $marié === "oui"
            ? $this->taxAdminData->plafondImpotCouplePourDecote
            : $this->taxAdminData->plafondImpotCelibatairePourDecote;
        if ($impots < $plafondImpôtPourDécôte) {
            // montant maximal de la décôte
            $plafondDécôte = $marié === "oui"
                ? $this->taxAdminData->plafondDecoteCouple
                : $this->taxAdminData->plafondDecoteCelibataire;
            // décôte théorique
            $décôte = $plafondDécôte - 0.75 * $impots;
            // la décôte ne peut dépasser le montant de l'impôt
            if ($décôte > $impots) {
                $décôte = $impots;
            }
            // pas de décôte < 0
            if ($décôte < 0) {
                $décôte = 0;
            }
        }
        // résultat
        return ceil($décôte);
    }

    // calcule une réduction éventuelle
    private function getRéduction(string $marié, float $salaire, int $enfants, float $impots): float
    {
        // le plafond des revenus pour avoir droit à la réduction de 20%
        $plafondRevenuPourRéduction = $marié === "oui"
            ? $this->taxAdminData->plafondRevenusCouplePourReduction
            : $this->taxAdminData->plafondRevenusCelibatairePourReduction;
        $plafondRevenuPourRéduction += $enfants * $this->taxAdminData->valeurReducDemiPart;
        if ($enfants > 2) {
            $plafondRevenuPourRéduction += ($enfants - 2) * $this->taxAdminData->valeurReducDemiPart;
        }
        // revenu imposable
        $revenuImposable = $this->getRevenuImposable($salaire);
        // réduction
        $réduction = 0;
        if ($revenuImposable < $plafondRevenuPourRéduction) {
            // réduction de 20%
            $réduction = 0.2 * $impots;
        }
        // résultat
        return ceil($réduction);
    }

    // --------------------------------------------------------------------------
    #[\Override]
    public function executeBatchImpots(string $taxPayersFileName, string $resultsFileName, string $errorsFileName): void
    {
        // les trois fichiers ne sont pas encore ouverts
        $errors = $results = $data = false;
        // pas mal d'erreurs peuvent se produire dès qu'on gère des fichiers
        try {
            // ouverture du fichier des erreurs
            $errors = fopen($errorsFileName, "w");
            if ($errors === false) {
                throw new ExceptionImpots("Impossible de créer le fichier des erreurs [$errorsFileName]", 10);
            }
            // ouverture du fichier des résultats
            $results = fopen($resultsFileName, "w");
            if ($results === false) {
                throw new ExceptionImpots("Impossible de créer le fichier des résultats [$resultsFileName]", 11);
            }
            // ouverture du fichier des données contribuables
            $data = is_readable($taxPayersFileName) ? fopen($taxPayersFileName, "r") : false;
            if ($data === false) {
                throw new ExceptionImpots("Impossible d'ouvrir en lecture les déclarations des contribuables [$taxPayersFileName]", 12);
            }
            // on exploite la ligne courante du fichier des données contribuables
            // qui a la forme statut marital, nombre d'enfants, salaire annuel
            $num = 0;         // n° ligne courante
            $nbErreurs = 0;   // nbre d'erreurs rencontrées
            while (($ligne = fgets($data, 100)) !== false) {
                // une ligne de plus
                $num++;
                // on enlève l'éventuelle marque de fin de ligne
                $ligne = Utilitaires::cutNewLineChar($ligne);
                // on ignore les lignes vides
                if (trim($ligne) === "") {
                    continue;
                }
                // la ligne doit avoir 3 champs marié,enfants,salaire
                $champs = array_map(trim(...), explode(",", $ligne));
                $erreur = count($champs) !== 3;
                if (!$erreur) {
                    [$marié, $enfants, $salaire] = $champs;
                    // le statut marital doit être oui ou non
                    $marié = strtolower($marié);
                    // le nombre d'enfants et le salaire doivent être des entiers positifs ou nuls
                    $erreur = !in_array($marié, ["oui", "non"], true)
                        || !preg_match('/^\d+$/', $enfants)
                        || !preg_match('/^\d+$/', $salaire);
                }
                // erreur ?
                if ($erreur) {
                    fputs($errors, "la ligne [$num] du fichier [$taxPayersFileName] est erronée\n");
                    $nbErreurs++;
                    continue;
                }
                // on calcule l'impôt
                $result = $this->calculerImpot($marié, (int) $enfants, (int) $salaire);
                // on inscrit le résultat dans le fichier des résultats
                $result = ["marié" => $marié, "enfants" => (int) $enfants, "salaire" => (int) $salaire] + $result;
                fputs($results, json_encode($result, JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR) . "\n");
            }
            // des erreurs ?
            if ($nbErreurs > 0) {
                throw new ExceptionImpots("Il y a eu $nbErreurs ligne(s) erronée(s) : voir le fichier [$errorsFileName]", 15);
            }
        } finally {
            // on ferme les fichiers qui ont été ouverts
            foreach ([$data, $results, $errors] as $fichier) {
                if ($fichier !== false) {
                    fclose($fichier);
                }
            }
        }
    }

    • line 185: the method receives three parameters:
      • [$taxPayersFileName]: the name of the text file containing the taxpayers' data. Each line of text contains the data of one taxpayer in the form: marital status (oui / non), number of children, annual salary, for example [oui,2,55555];

    • line 188: the variables of the three files are initialized to [false] (file not open). This will let us know, in the [finally] clause, which files have been opened;
    • line 190: because a number of operations may throw an exception, a [try / finally] structure surrounds all the code of the method;
    • lines 192-204: the three files are opened. An exception is thrown as soon as an opening fails, with a different error code for each case;
    • line 210: the lines of the [$data] file are read one by one, at most 100 characters at a time (all lines are shorter than 100 characters);

    • lines 216-218: empty lines (for example at the end of the file) are ignored;

    • line 221: the line must have exactly three fields. The PHP 7 course wrote directly [list($marié, $enfants, $salaire) = explode(",", $ligne)]: with a line having only two fields, PHP 8 emits an "Undefined array key 2" warning;
    • lines 227-229: the validity of the three elements is checked: the marital status must be oui or non, the number of children and the salary must be non-negative integers (a sequence of digits, regular expression [/^\d+$/]). The third parameter [true] of [in_array] requests a strict [===] comparison;
    • lines 232-236: we do not throw an exception if the line is erroneous; instead we write an error message to the [$errors] text file and move on to the next line;
    • line 238: if the line read is valid, the tax calculation is performed. We get a result in the form of an associative array [impôt, surcôte, décôte, réduction, taux];

    $impots->executeBatchImpots(TAXPAYERSDATA_FILENAME, RESULTS_FILENAME, ERRORS_FILENAME);
} catch (ExceptionImpots $ex) {
    // on affiche l'erreur
    print "Erreur n° {$ex->getCode()} : {$ex->getMessage()}\n";
}
// fin
print "Terminé\n";

    Comments

    • line 4: we enforce strict compliance with the types of function parameters;
    • line 7: the [main.php] script is also placed in the [Application] namespace;
    • lines 10-15: we load the files of the classes and interfaces used by the script. Note that here we have not used a [use] statement to declare the fully qualified name of the classes used by the script. It is indeed unnecessary because the script and the classes are in the same [Application] namespace. Note also the loading order: a parent class or an interface must be loaded before the class that extends or implements it;
    • lines 18-21: the names of the files used in the script. These names are relative: the files are looked for in the current folder, the one from which the script is executed;
    • line 25: an [ImpotsWithTaxAdminDataInJsonFile] object is created. This may cause an exception if the JSON file is missing or incorrect;
    • line 27: we execute the [executeBatchImpots] method, which will calculate the taxes for all the taxpayers in the [TAXPAYERSDATA_FILENAME] file. The results will be put in the [RESULTS_FILENAME] file and any errors in the [ERRORS_FILENAME] file;
    • lines 28-31: in case of error, we display the error's code and message. The expression [{$ex->getCode()}] lets you insert the result of a method call into a string.

    8.10. Conclusion

    Version 3 has the same functionality as version 2 but is better equipped to deal with errors: incomplete or incorrect tax data, erroneous lines in the taxpayers' file, missing files. Each error is reported by an [ExceptionImpots] exception carrying a precise message and code.

    The [AbstractBaseImpots] class, however, mixes two kinds of code: the tax calculation on the one hand, reading and writing files on the other. We will see in the following chapters how to separate these two concerns into different layers.
