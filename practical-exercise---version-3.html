    8. Practical Exercise – Version 3

    We’ll revisit the exercise we covered earlier (versions 1 and 2) and solve it using code PHP that employs classes. We’ll put into practice what we’ve learned in the previous three chapters:

    • an (immutable) [readonly] class to represent tax administration data;
    • an interface, an abstract class that partially implements it, and a derived class that completes it;
    • a single exception type, [ExceptionImpots], to report all application errors;
    • the [#[\Override]] attribute on all methods that implement an interface method or override a parent method.

    Comments

    • Line 6: The class [ExceptionImpots] is in the [Application] namespace. All classes and interfaces in the tax calculation application will be in this namespace;
    • line 9: The class [ExceptionImpots] extends the predefined class PHP [RuntimeException]. As we saw in the chapter on exceptions, an exception is primarily defined by its type: it is the type that allows it to be caught with a [catch (ExceptionImpots $ex)] clause;
    • Lines 11–12: The PHP 7 course defined a constructor [__construct(string $message, int $code = 0)] that simply called the parent class’s constructor. It is unnecessary: the class inherits the constructor from [RuntimeException], which accepts a message, an error code, and any previous exception. We’ll use this last parameter to encapsulate a low-level exception (a [JsonException], for example) within a [ExceptionImpots].

    <?php

declare(strict_types=1);

// namespace
namespace Application;

// tax administration data: an immutable object
final readonly class TaxAdminData
{
     // the names of arrays and constants expected in the data
    private const array TABLEAUX = ["limites", "coeffR", "coeffN"];
    private const array CONSTANTES = [
        "plafondQfDemiPart",
        "plafondRevenusCelibatairePourReduction",
        "plafondRevenusCouplePourReduction",
        "valeurReducDemiPart",
        "plafondDecoteCelibataire",
        "plafondDecoteCouple",
        "plafondImpotCouplePourDecote",
        "plafondImpotCelibatairePourDecote",
        "abattementDixPourcentMax",
        "abattementDixPourcentMin",
    ];

     // private constructor: you must use the methods [from...]
    private function __construct(
         // tax brackets
        public array $limites,
        public array $coeffR,
        public array $coeffN,
         // tax calculation constants
        public float $plafondQfDemiPart,
        public float $plafondRevenusCelibatairePourReduction,
        public float $plafondRevenusCouplePourReduction,
        public float $valeurReducDemiPart,
        public float $plafondDecoteCelibataire,
        public float $plafondDecoteCouple,
        public float $plafondImpotCouplePourDecote,
        public float $plafondImpotCelibatairePourDecote,
        public float $abattementDixPourcentMax,
        public float $abattementDixPourcentMin,
    ) {
    }

     // Generation from a file JSON
    public static function fromJsonFile(string $taxAdminDataFilename): self
    {
         // retrieve the contents of the tax data file
        $fileContents = is_readable($taxAdminDataFilename) ? file_get_contents($taxAdminDataFilename) : false;
         // error?
        if ($fileContents === false) {
            throw new ExceptionImpots("Le fichier des données [$taxAdminDataFilename] n'existe pas", 1);
        }
         // Decode the JSON into an associative array
        try {
            $data = json_decode($fileContents, true, flags: JSON_THROW_ON_ERROR);
        } catch (\JsonException $ex) {
            throw new ExceptionImpots("Le fichier de données JSON [$taxAdminDataFilename] n'a pu être exploité correctement", 2, $ex);
        }
         // JSON must be an object {...}
        if (!is_array($data)) {
            throw new ExceptionImpots("Le fichier de données JSON [$taxAdminDataFilename] ne contient pas un objet JSON", 3);
        }
         // constructing the object from the associative array
        return self::fromArray($data);
    }

     // constructing from an associative array [nom => valeur]
    public static function fromArray(array $data): self
    {
         // The keys present must be exactly those expected
        $attendues = [...self::TABLEAUX, ...self::CONSTANTES];
        $manquante = array_first(array_diff($attendues, array_keys($data)));
        if ($manquante !== null) {
            throw new ExceptionImpots("L'attribut [$manquante] de [TaxAdminData] n'a pas été initialisé", 4);
        }
        $inconnue = array_first(array_diff(array_keys($data), $attendues));
        if ($inconnue !== null) {
            throw new ExceptionImpots("L'attribut [$inconnue] n'existe pas dans [TaxAdminData]", 5);
        }
         // Each value is checked and converted
        $valeurs = [];
        foreach (self::TABLEAUX as $clé) {
             // a non-empty array of real numbers >= 0
            if (!is_array($data[$clé]) || !array_is_list($data[$clé]) || count($data[$clé]) === 0) {
                throw new ExceptionImpots("La valeur de l'attribut [$clé] est invalide", 6);
            }
            $valeurs[$clé] = array_map(fn(mixed $valeur): float => self::check($clé, $valeur), $data[$clé]);
        }
         // The three arrays must be the same size
        $taille = count($valeurs["limites"]);
        if (count($valeurs["coeffR"]) !== $taille || count($valeurs["coeffN"]) !== $taille) {
            throw new ExceptionImpots("Les tableaux [limites, coeffR, coeffN] n'ont pas la même taille", 7);
        }
        foreach (self::CONSTANTES as $clé) {
             // a real number >= 0
            $valeurs[$clé] = self::check($clé, $data[$clé]);
        }
         // object construction: the array keys become named arguments
        return new self(...$valeurs);
    }

     // checks whether a value is a positive real number or zero and returns it in the form of [float]
    private static function check(string $clé, mixed $value): float
    {
         // accepts 1551, 1551.78, "1551" but not "xx", true, null, -3...
        if ((is_int($value) || is_float($value) || (is_string($value) && is_numeric($value)))
            && (float) $value >= 0) {
            return (float) $value;
        }
        throw new ExceptionImpots("La valeur de l'attribut [$clé] est invalide", 6);
    }

     // string JSON of the object
    public function __toString(): string
    {
        return json_encode(get_object_vars($this), JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR);
    }
}

    Comments

    • Line 9: The class is [readonly]: All of its attributes are read-only. Once created, a [TaxAdminData] object can no longer be modified: it can be safely shared among all parts of the application. It is also [final]: it cannot be derived;
    • lines 12–24: two private class constants list the names of the attributes expected in the data. Starting with PHP 8.3, a class constant can be typed (here, [array]);
    • lines 27–43: The constructor uses parameter promotion: each parameter becomes a public attribute with the same name and type. The attributes have the same names as the keys in the JSON file. This is an important point that greatly simplifies code writing, as we will see. The tax brackets are arrays ([array]), and the calculation constants are real numbers ([float]). In PHP 7, attributes could not be typed (as noted in the PHP 7 course); they can be typed starting with PHP 7.4;
    • Line 27: The constructor is private; [new TaxAdminData(...)] cannot be written outside the class. A [TaxAdminData] object can only be obtained through the static methods [fromJsonFile] and [fromArray], which verify the validity of the data. This ensures that every [TaxAdminData] object contains valid data. In PHP, a class can have only one constructor. Static methods that construct an object—sometimes called “named constructors”—allow for multiple ways to construct an object. Course PHP 7 used instance methods [setFromJsonFile] called on an empty object: [(new TaxAdminData())->setFromJsonFile(...)]. This is impossible with an immutable object;
    • Lines 47–67: The [fromJsonFile] method constructs a [TaxAdminData] object from the JSON file, whose name is passed to it. Its return type, [self], refers to the class itself;
    • lines 50–53: The file’s contents are read. If this is not possible, a [ExceptionImpots] exception is thrown. This exception will propagate up to the main script;
    • lines 56–60: The file’s content, JSON, is decoded. With the option [JSON_THROW_ON_ERROR] (PHP 7.3), the [json_decode] function throws a [JsonException] exception when the JSON is invalid, instead of silently returning [null]. Note the named argument [flags:], which avoids having to assign a value to the third parameter [depth] of [json_decode]. The exception [JsonException] is encapsulated within a [ExceptionImpots]: the calling code only has to handle one exception type but can determine the original cause using [$ex->getPrevious()];
    • lines 62–64: a file containing, for example, only the number 12 is a valid JSON; you must verify that an array has indeed been obtained;
    • line 66: the rest of the work is delegated to the [fromArray] method. This method is public: it may be used in a future version where tax administration data comes from a database;
    • Lines 73–81: We verify that the keys in the array [$data] are exactly the expected names. [[...self::TABLEAUX, ...self::CONSTANTES]] creates an array containing the elements from both arrays. The function [array_diff] removes the elements from the first table that are not present in the second, and the function [array_first] (PHP 8.5) returns the first element of an array or [null] if the array is empty. This detects a missing key followed by an unknown key. This is the most common error: a typo in an attribute name in the [taxadmindata.json] file. In course PHP 7, the loop [$this->$key = $value] silently created a dynamic attribute with the incorrect name. Since PHP 8.2, the creation of dynamic attributes has been deprecated, and it is prohibited within a [readonly] class;
    • lines 84–90: Each of the three arrays must be a non-empty list (function [array_is_list], PHP 8.1) whose elements are all positive or zero real numbers. The function [array_map] applies the method [check] to each element;
    • lines 92–95: The three tax bracket arrays must be the same size;
    • lines 96–99: Each of the calculation constants must be a positive real number or zero;
    • Line 101: The array [$valeurs] uses the names of the constructor’s parameters as keys. The operator [...], when applied to an array with string keys, converts each element into a named argument (PHP 8.1): this line is equivalent to [new self(limites: $valeurs["limites"], coeffR: $valeurs["coeffR"], ...)]. This is where choosing identical names for the JSON keys and the class attributes simplifies the code;
    • Lines 105–113: The method [check] checks whether a value [$value] of unknown type ([mixed]) is a positive number or zero. According to the information in the JSON file, the value read can be an integer (1551), a floating-point number (1551.78), a string convertible to a number ("1551"), a non-convertible string ("xx"), a Boolean... The function [is_numeric] returns [true] for a string representing a number. The PHP 7 course performed this check using a regular expression and returned a [stdClass] object indicating whether an error had occurred. Here, an error triggers an exception, and the method simply returns the number in the form of a [float];
    • Line 116: The [__toString] method returns the JSON string containing the object’s attributes. The [get_object_vars] function returns a [nom de l'attribut => valeur] associative array.

    8.3.1. Why are there no longer any getters and setters?

    Course PHP 7 declared the attributes as private and wrote a getter and a setter for each one (26 methods), automatically generated by IDE and NetBeans. The setters were “fluent”: they returned the [$this] object, which allowed for chained calls to [$data->setLimites($limites)->setCoeffR($coeffR)].

    With PHP 8, this code is no longer necessary:

    • the getters were used to read private attributes. The attributes [readonly] can safely be made public since they cannot be modified: we write [$taxAdminData->plafondQfDemiPart] instead of [$taxAdminData->getPlafondQfDemiPart()];
    • the setters were used to initialize the object and allowed for value validation. An immutable object is initialized once and for all by its constructor, and validation is performed by the methods [fromJsonFile] and [fromArray];
    • Typed attributes guarantee the type of the values. The PHP 7 course noted that the [$this->plafondQfDemiPart = 'abcd'] statement was possible: with attributes [float] and [declare(strict_types=1)], it causes an error [TypeError].

    }

    public function calculerImpot(string $marié, int $enfants, int $salaire): array
    {
         // $marié: yes, no
         // $enfants: number of children
         // $salaire: annual salary
         // $this->taxAdminData: data from the tax authorities
        //
         // Retrieve tax authority data if it hasn't already been done

         // Calculate tax with children
        $result1 = $this->calculerImpot2($marié, $enfants, $salaire);
        $impot1 = $result1["impôt"];
         // Calculate tax without children
        if ($enfants !== 0) {
            $result2 = $this->calculerImpot2($marié, 0, $salaire);
            $impot2 = $result2["impôt"];
             // Apply the family quotient cap
            $plafondDemiPart = $this->taxAdminData->plafondQfDemiPart;

                $impot2 = $impot2 - 2 * $plafondDemiPart - ($enfants - 2) * 2 * $plafondDemiPart;
            }
        } else {
            $impot2 = $impot1;
            $result2 = $result1;
        }
         // We use the highest tax amount with the corresponding rate and surcharge
        if ($impot1 > $impot2) {
            $impot = $impot1;
            $taux = $result1["taux"];
            $surcôte = $result1["surcôte"];
        } else {
            $surcôte = $impot2 - $impot1 + $result2["surcôte"];
            $impot = $impot2;
            $taux = $result2["taux"];
        }
         // Calculation of a possible tax reduction
        $décôte = $this->getDecote($marié, $salaire, $impot);

         // Calculation of a potential tax reduction
        $réduction = $this->getRéduction($marié, $salaire, $enfants, $impot);
        $impot -= $réduction;
         // Result
        return [
            "impôt" => (int) floor($impot),
            "surcôte" => (int) $surcôte,
            "décôte" => (int) $décôte,
            "réduction" => (int) $réduction,
            "taux" => $taux,
        ];

    private function calculerImpot2(string $marié, int $enfants, float $salaire): array
    {
         // number of shares
        $nbParts = match ($marié) {
            "oui" => $enfants / 2 + 2,
            "non" => $enfants / 2 + 1,
        };
         // 1 share per child starting with the third
        if ($enfants >= 3) {
             // half an additional share for each child starting with the third
            $nbParts += 0.5 * ($enfants - 2);
        }
         // taxable income
        $revenuImposable = $this->getRevenuImposable($salaire);
         // surcharge
        $surcôte = floor($revenuImposable - 0.9 * $salaire);
         // for rounding issues
        if ($surcôte < 0) {
            $surcôte = 0;
        }
         // family quotient
        $quotient = $revenuImposable / $nbParts;
         // tax brackets (copies of the object's tables)
        $limites = $this->taxAdminData->limites;
        $coeffR = $this->taxAdminData->coeffR;
        $coeffN = $this->taxAdminData->coeffN;
         // is placed at the end of the limits table to stop the following loop
        $limites[count($limites) - 1] = $quotient;
         // tax calculation
        $i = 0;
        while ($quotient > $limites[$i]) {
            $i++;
        }
         // Now we can calculate the tax
        $impôt = floor($revenuImposable * $coeffR[$i] - $nbParts * $coeffN[$i]);
         // result
        return ["impôt" => $impôt, "surcôte" => $surcôte, "taux" => $coeffR[$i]];
    }

     // revenuImposable = annual salary - deduction
     // The deduction has a minimum and a maximum
    private function getRevenuImposable(float $salaire): float
    {
         // a deduction of 10% of the salary, limited by a minimum and a maximum
        $abattement = 0.1 * $salaire;
        $abattement = min($abattement, $this->taxAdminData->abattementDixPourcentMax);
        $abattement = max($abattement, $this->taxAdminData->abattementDixPourcentMin);
         // taxable income
        $revenuImposable = $salaire - $abattement;
         // Result
        return floor($revenuImposable);
    }

     // Calculates a possible discount
    private function getDecote(string $marié, float $salaire, float $impots): float
    {
         // Initially, a zero discount
        $décôte = 0;
         // maximum tax amount to qualify for the tax reduction
        $plafondImpôtPourDécôte = $marié === "oui"
            ? $this->taxAdminData->plafondImpotCouplePourDecote
            : $this->taxAdminData->plafondImpotCelibatairePourDecote;
        if ($impots < $plafondImpôtPourDécôte) {
             // maximum discount amount
            $plafondDécôte = $marié === "oui"
                ? $this->taxAdminData->plafondDecoteCouple
                : $this->taxAdminData->plafondDecoteCelibataire;
             // theoretical discount
            $décôte = $plafondDécôte - 0.75 * $impots;
             // The discount cannot exceed the tax amount
            if ($décôte > $impots) {
                $décôte = $impots;
            }
             // No discount < 0
            if ($décôte < 0) {
                $décôte = 0;
            }
        }
         // Result
        return ceil($décôte);
    }

     // calculates a possible reduction
    private function getRéduction(string $marié, float $salaire, int $enfants, float $impots): float
    {
         // the income threshold for eligibility for the 20% reduction
        $plafondRevenuPourRéduction = $marié === "oui"
            ? $this->taxAdminData->plafondRevenusCouplePourReduction
            : $this->taxAdminData->plafondRevenusCelibatairePourReduction;
        $plafondRevenuPourRéduction += $enfants * $this->taxAdminData->valeurReducDemiPart;
        if ($enfants > 2) {
            $plafondRevenuPourRéduction += ($enfants - 2) * $this->taxAdminData->valeurReducDemiPart;
        }
         // taxable income
        $revenuImposable = $this->getRevenuImposable($salaire);
         // reduction
        $réduction = 0;
        if ($revenuImposable < $plafondRevenuPourRéduction) {
             // 20% reduction
            $réduction = 0.2 * $impots;
        }
         // result
        return ceil($réduction);
    }

    public function executeBatchImpots(string $taxPayersFileName, string $resultsFileName, string $errorsFileName): void
    {
         // The three files are not yet open
        $errors = $results = $data = false;
         // Quite a few errors can occur when managing files
        try {
             // Opening the error file
            $errors = fopen($errorsFileName, "w");
            if ($errors === false) {
                throw new ExceptionImpots("Impossible de créer le fichier des erreurs [$errorsFileName]", 10);
            }
             // opening the results file
            $results = fopen($resultsFileName, "w");
            if ($results === false) {
                throw new ExceptionImpots("Impossible de créer le fichier des résultats [$resultsFileName]", 11);
            }
             // Opening the taxpayer data file
            $data = is_readable($taxPayersFileName) ? fopen($taxPayersFileName, "r") : false;
            if ($data === false) {
                throw new ExceptionImpots("Impossible d'ouvrir en lecture les déclarations des contribuables [$taxPayersFileName]", 12);
            }
             // Processing the current row of the taxpayer data file
             // which has the format: marital status, number of children, annual salary
            $num = 0;         // current line number
            $nbErreurs = 0;   // Number of errors encountered
            while (($ligne = fgets($data, 100)) !== false) {
                 // one more row
                $num++;
                 // Remove any end-of-row marker
                $ligne = Utilitaires::cutNewLineChar($ligne);
                 // empty lines are ignored
                if (trim($ligne) === "") {
                    continue;
                }
                 // The line must contain the three fields: married, children, salary
                $champs = array_map(trim(...), explode(",", $ligne));
                $erreur = count($champs) !== 3;
                if (!$erreur) {
                    [$marié, $enfants, $salaire] = $champs;
                     // the marital status must be "yes" or "no"
                    $marié = strtolower($marié);
                     // The number of children and the salary must be positive integers or zero
                    $erreur = !in_array($marié, ["oui", "non"], true)
                        || !preg_match('/^\d+$/', $enfants)
                        || !preg_match('/^\d+$/', $salaire);
                }
                 // Error?
                if ($erreur) {
                    fputs($errors, "la ligne [$num] du fichier [$taxPayersFileName] est erronée\n");
                    $nbErreurs++;
                    continue;
                }
                 // Calculate the tax
                $result = $this->calculerImpot($marié, (int) $enfants, (int) $salaire);
                 // The result is written to the results file
                $result = ["marié" => $marié, "enfants" => (int) $enfants, "salaire" => (int) $salaire] + $result;
                fputs($results, json_encode($result, JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR) . "\n");
            }
             // Any errors?
            if ($nbErreurs > 0) {
                throw new ExceptionImpots("Il y a eu $nbErreurs ligne(s) erronée(s) : voir le fichier [$errorsFileName]", 15);
            }
        } finally {
             // Closing the files that were opened
            foreach ([$data, $results, $errors] as $fichier) {
                if ($fichier !== false) {
                    fclose($fichier);
                }
            }
        }
    }

    8.10. Conclusion

    Version 3 has the same functionality as version 2 but is better equipped to handle errors: incomplete or incorrect tax data, erroneous lines in the taxpayer file, or missing files. Each error is flagged by a [ExceptionImpots] exception that includes a message and a specific code.
