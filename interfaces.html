    6. Interfaces

    An interface is a structure that defines method prototypes. A class implementing an interface must define the code of all the interface's methods. An interface is a contract: it says what an object can do, without saying how it does it.

    <?php

// respect strict des types déclarés des paramètres de fonctions
declare(strict_types=1);

// espace de noms
namespace Exemples;

// une interface
interface IExemple
{
    // les méthodes de l'interface
    public function ajouter(int $i, int $j): int;

    public function soustraire(int $i, int $j): int;
}

// implémentation 1 de l'interface IExemple
class Classe1 implements IExemple
{
    public function ajouter(int $a, int $b): int
    {
        return $a + $b + 10;
    }

    public function soustraire(int $a, int $b): int
    {
        return $a - $b + 20;
    }
}

// implémentation 2 de l'interface IExemple
class Classe2 implements IExemple
{
    public function ajouter(int $a, int $b): int
    {
        return $a + $b + 100;
    }

    public function soustraire(int $a, int $b): int
    {
        return $a - $b + 200;
    }
}

    Comments

    • lines 10-15: the [IExemple] interface defines two methods: the [ajouter] function (line 13) and the [soustraire] function (line 15). The interface does not define the code of these methods. The classes implementing the interface will do that. The methods of an interface are necessarily public;
    • line 19: the [Classe1] class implements ([implements]) the [IExemple] interface. It therefore defines code for the methods [ajouter] (line 21) and [soustraire] (line 26). The parameter names may differ from those of the interface ([$a] instead of [$i]) but their types must be compatible. Be careful, however: with PHP 8 named arguments, a call [ajouter(i: 1, j: 2)] would not work with [Classe1]. It is therefore preferable to keep the interface's names;
    • lines 33-44: the same for the [Classe2] class.

    <?php

declare(strict_types=1);

// inclusion et déclaration des classes et interfaces utilisées par le script
require_once __DIR__ . "/IExemple.php";

use Exemples\Classe2;
use Exemples\IExemple;

// fonction
function calculer(int $a, int $b, IExemple $interface): void
{
    print $interface->ajouter($a, $b) . "\n";
    print $interface->soustraire($a, $b) . "\n";
}

// ------------------- main
// création de 2 objets de type Classe1 et Classe2
$c1 = new Classe1();
$c2 = new Classe2();
// appel de la fonction calculer
calculer(4, 3, $c1);
calculer(14, 13, $c2);
// une interface ne peut pas être instanciée
try {
    new IExemple();
} catch (\Error $e) {
    print "Erreur : " . $e->getMessage() . "\n";
}

    Comments

    • lines 15-16: we use the [ajouter, soustraire] methods of the [IExemple] interface;
    • line 24: the 3rd actual parameter is of type [Classe1], compatible with the [IExemple] type of the function's 3rd formal parameter;
    • line 25: the same for the [Classe2] class;
    • line 28: an interface cannot be instantiated: we get an error (line 6 of the results).

    In the same way that a child class can extend a parent class, a child interface can extend a parent interface.

    <?php

// respect strict des types déclarés des paramètres de fonctions
declare(strict_types=1);

// espace de noms
namespace Exemples;

// inclusion de la définition de l'interface IExemple
require_once __DIR__ . "/IExemple.php";

// une interface qui dérive de IExemple
interface IExemple2 extends IExemple
{
    // la méthode ajoutée par l'interface
    public function multiplier(int $i, int $j): int;
}

// implémentation de l'interface IExemple2
class Classe3 extends Classe2 implements IExemple2
{
    // [Override] vérifie que la méthode existe bien dans l'interface
    #[\Override]
    public function multiplier(int $a, int $b): int
    {
        return $a * $b;
    }
}

    Comments

    • line 7: the [IExemple2] interface will be in the same namespace as the [IExemple] interface;
    • line 10: we include the file defining the [IExemple] interface;
    • lines 13-17: define the [IExemple2] interface, which extends ([extends]) the [IExemple] interface and adds a new method to it (line 16). An interface can even extend several interfaces: [interface I3 extends I1, I2];
    • lines 20-28: the [Classe3] class extends the [Classe2] class. Since the latter implements the [IExemple] interface, so will the [Classe3] class. Indeed, [Classe3] inherits all the public and protected methods of the [Classe2] class, and therefore the [ajouter] and [soustraire] methods. In addition, we state that [Classe3] implements the [IExemple2] interface. As such, it must also implement the [multiplier] method, which [Classe2] does not. This is what lines 24-27 do;
    • line 23: since PHP 8.3, the [#[\Override]] attribute, encountered in the previous chapter, also applies to a method that implements an interface method. If the [multiplier] method disappeared from the [IExemple2] interface, PHP would report it.

    <?php

// respect strict des types déclarés des paramètres de fonctions
declare(strict_types=1);

// inclusion et déclaration des classes et interfaces nécessaires au script
require_once __DIR__ . "/IExemple.php";
require_once __DIR__ . "/IExemple2.php";
use Exemples\IExemple;
use Exemples\IExemple2;
use Exemples\Classe1;
use Exemples\Classe3;

// fonction
function calculer(int $a, int $b, IExemple $interface): void
{
    print $interface->ajouter($a, $b) . "\n";
    print $interface->soustraire($a, $b) . "\n";
}

// ------------------- main
// création d'1 objet de type Classe3 qui implémente IExemple2 et donc IExemple
$c3 = new Classe3();
// appel de la fonction calculer
calculer(4, 3, $c3);
// l'opérateur [instanceof] teste si un objet implémente une interface
foreach ([new Classe1(), $c3] as $objet) {
    print $objet::class . " : IExemple=" . var_export($objet instanceof IExemple, true)
        . ", IExemple2=" . var_export($objet instanceof IExemple2, true) . "\n";
}
// les interfaces implémentées par la classe Classe3
print_r(class_implements($c3));

    • lines 27-30: the [instanceof] operator tests whether an object implements an interface. A [Classe1] object implements [IExemple] but not [IExemple2] (line 4 of the results). A [Classe3] object implements both (line 5);
    • line 32: the [class_implements] function returns the list of interfaces implemented by an object or a class, directly or through inheritance (lines 6-10 of the results).

    <?php

// respect strict des types déclarés des paramètres de fonctions
declare(strict_types=1);

// espace de noms
namespace Exemples;

// une interface peut déclarer des constantes
interface ICalcul
{
    // constante typée (PHP 8.3)
    public const int PRECISION = 2;

    public function calculer(float $a, float $b): float;
}

// une seconde interface
interface INommable
{
    public function getNom(): string;
}

// une classe peut implémenter plusieurs interfaces
final class Addition implements ICalcul, INommable
{
    #[\Override]
    public function calculer(float $a, float $b): float
    {
        return round($a + $b, self::PRECISION);
    }

    #[\Override]
    public function getNom(): string
    {
        return "addition";
    }
}

final class Division implements ICalcul, INommable
{
    #[\Override]
    public function calculer(float $a, float $b): float
    {
        // [ICalcul::PRECISION] et [self::PRECISION] désignent la même constante
        return round($a / $b, ICalcul::PRECISION);
    }

    #[\Override]
    public function getNom(): string
    {
        return "division";
    }
}

    Comments

    • line 13: the [ICalcul] interface declares a constant. All classes that implement the interface inherit it. Since PHP 8.3, a class or interface constant can be typed (here [int]);
    • lines 19-22: a second interface, with a single method;
    • line 25: the [Addition] class implements both interfaces: the interface names are separated by commas. It must define the methods of both;
    • line 30: the constant inherited from the interface is reached through [self::PRECISION]. The [round] function rounds a number to the given number of decimal places;
    • line 46: the constant can also be designated by the interface name: [ICalcul::PRECISION].

    <?php

// respect strict des types déclarés des paramètres de fonctions
declare(strict_types=1);

// inclusion et déclaration des classes et interfaces nécessaires au script
require_once __DIR__ . "/ICalcul.php";
use Exemples\ICalcul;
use Exemples\INommable;
use Exemples\Addition;
use Exemples\Division;

// le paramètre [$calcul] a une valeur par défaut : un objet créé par [new] (PHP 8.1)
function executer(float $a, float $b, ICalcul $calcul = new Addition()): float
{
    return $calcul->calculer($a, $b);
}

// type intersection (PHP 8.1) : [$operation] doit implémenter les deux interfaces
function afficher(float $a, float $b, ICalcul&INommable $operation): void
{
    print $operation->getNom() . "($a, $b)=" . $operation->calculer($a, $b) . "\n";
}

// ------------------- main
// constante de l'interface
print "précision : " . ICalcul::PRECISION . " décimales\n";
// valeur par défaut du 3e paramètre
print "executer(1.234, 2.345)=" . executer(1.234, 2.345) . "\n";
// paramètre explicite
print "executer(10, 3, new Division())=" . executer(10, 3, new Division()) . "\n";
// type intersection
afficher(10, 4, new Division());
afficher(10, 4, new Addition());
// les classes implémentent les deux interfaces
print_r(class_implements(Division::class));

    Comments

    • line 14: the 3rd parameter of the [executer] function is of type [ICalcul] and has a default value, an [Addition] object created with [new]. Up to PHP 8.0, the default value of a parameter could only be a constant. Since PHP 8.1, the [new] expression is accepted in parameter default values ("new in initializers"), as well as in the arguments of PHP attributes ([#[...]]), static variables and global constants. It remains forbidden in the default value of a class property. The object is created on each call that omits the parameter;
    • line 20: the type [ICalcul&INommable] is an intersection type (PHP 8.1): the actual parameter must implement both [ICalcul] and [INommable]. The function can then call the methods of both interfaces. It must not be confused with the union type [ICalcul|INommable] (one or the other);
    • line 27: the constant is accessible from outside through the interface name (line 2 of the results);
    • line 29: the 3rd parameter is omitted: an [Addition] object performs the calculation (line 3);
    • line 31: we explicitly pass a [Division] object (line 4). Note that the integers 10 and 3 are accepted for [float] parameters despite the [strict_types=1] declaration: converting an [int] to a [float] is the only automatic conversion allowed in strict mode;
    • lines 33-34: both classes implement both interfaces: they are accepted by the [afficher] function (lines 5-6);
    • line 36: the notation [Division::class] returns the fully qualified class name, here [Exemples\Division]. The [class_implements] function accepts a class name as well as an object.

    Interfaces are ubiquitous in PHP itself. We have already encountered two of them in the previous chapter: [Stringable], implemented automatically by any class having a [__toString] method, and [JsonSerializable], which lets you control the JSON encoding of an object. In the next chapter we will meet the [Throwable] interface, implemented by all errors and exceptions. An enumeration can also implement an interface. Finally, we will see later in the course that interfaces are the foundation of the layered architecture of our applications: each layer knows only the interface of the neighbouring layer.
