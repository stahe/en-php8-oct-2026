    21. Processing XML Documents

    The web services we have written so far exchange JSON data. The XML (eXtensible Markup Language) has long been the most widely used exchange format, and it is still commonly encountered: SOAP web services, RSS feeds, configuration files, office documents (a [.odt] or [.docx] file is an archive of XML files). PHP provides two API files for working with it:

    • [SimpleXML]: a very simple API, where the document elements become object properties;
    • [DOM] (Document Object Model): the standard API of W3C, which is more comprehensive and also allows you to modify a document. PHP 8.4 introduced a new version, in the [Dom] namespace, compliant with the current web standard.

    <?xml version="1.0" encoding="UTF-8"?>

<tribu>
    <enseignant>
        <personne sexe="M">
            <nom>dupont</nom>
            <prenom>jean</prenom>
            <age>28</age>
            ceci est un commentaire
        </personne>
        <section>27</section>
    </enseignant>
    <etudiant>
        <personne sexe="F">
            <nom>martin</nom>
            <prenom>charline</prenom>
            <age>22</age>
        </personne>
        <formation>dess IAIE</formation>
    </etudiant>
</tribu>

    A XML document is a tree of elements:

    • line 1: the prolog, which specifies the version of XML and the document’s character encoding;
    • lines 3–21: the root element [tribu]. A XML document has exactly one root;
    • lines 4–12: the [enseignant] element, a child of [tribu]. It has two children, [personne] and [section];
    • line 5: the element [personne] has an attribute [sexe] with a value of [M];
    • line 9: an element can contain both other elements and text;
    • lines 13–20: the element [etudiant], which has the same structure as [enseignant].

    <?php

declare(strict_types=1);

// the XML file to be processed
const FILE_NAME = "data.xml";

// Loading the document XML
$xml = simplexml_load_file(FILE_NAME);
if ($xml === false) {
    print "Le fichier [" . FILE_NAME . "] n'a pu être exploité\n";
    exit(1);
}
// displaying the document
print_r($xml);
// the teacher’s attribute [sexe]
print_r($xml->enseignant->personne['sexe']);
// element and attribute values, converted to strings
$nom = (string) $xml->enseignant->personne->nom;
print "nom=$nom\n";
$sexe = (string) $xml->enseignant->personne['sexe'];
print "sexe=$sexe\n";
$formation = (string) $xml->etudiant->formation;
print "formation=$formation\n";
// existence of an element
print "isset(nom)=" . var_export(isset($xml->enseignant->personne->nom), true) . "\n";
print "isset(xx)=" . var_export(isset($xml->enseignant->personne->xx), true) . "\n";
// an integer conversion
$age = (int) $xml->etudiant->personne->age;
print "âge de l'étudiante=$age\n";
// iteration over all <person> elements in the document with XPath
foreach ($xml->xpath('//person') as $personne) {
    print "personne : {$personne->prenom} {$personne->nom} ({$personne['sexe']})\n";
}

    Comments

    • line 6: The filename XML is a constant. The script is executed in its own folder, that of [data.xml];
    • Line 9: The [simplexml_load_file] function loads the document and returns an object of type [SimpleXMLElement], which represents the root element [tribu]. In the event of an error (missing file, malformed XML), it returns [false], which we test on line 10;
    • line 15: display of the document. [print_r] shows how [SimpleXML] views the tree XML;
    • line 17: child elements are accessed as properties ([$xml->enseignant->personne]), and attributes as array keys ([['sexe']]). Note that the root [tribu] does not appear in the code: [$xml] is already that element;
    • line 19: [$xml->enseignant->personne->nom] is not a string but an object [SimpleXMLElement]. Converting [(string)] yields its text. With [declare(strict_types=1)], it is best to perform this conversion explicitly before passing the value to a function that expects a string;
    • Line 21: the value of the [sexe] attribute;
    • Lines 26–27: [isset] determines whether an element exists. The script PHP 7 displayed the Boolean result using [print], which returns [1] for [true] and an empty string for [false]. We use [var_export], which displays [true] or [false];
    • line 29: the conversion [(int)] returns the integer value of the element’s text;
    • line 32: the method [xpath] evaluates an expression XPath. The expression [//personne] refers to all [personne] elements in the document, regardless of their level. This returns an array of [SimpleXMLElement].

    21.3. Processing with the new API DOM from PHP 8.4

    Starting with PHP 8.4, the [Dom] namespace offers a new API and DOM: the [Dom\XMLDocument] class for XML documents and the [Dom\HTMLDocument] class for HTML5 documents. It is a better replacement for the old [DOMDocument] class (which is still available): it complies with the current DOM standard and provides the [querySelector] and [querySelectorAll] methods familiar to JavaScript developers. These methods allow you to search for elements using CSS selectors.

    <?php

declare(strict_types=1);

// the same document processed using the new API DOM from PHP 8.4

use Dom\XMLDocument;

// the XML file to be processed
const FILE_NAME = "data.xml";

try {
     // Loading the XML document
    $document = XMLDocument::createFromFile(FILE_NAME);
} catch (Throwable $ex) {
    print "Le fichier [" . FILE_NAME . "] n'a pu être exploité : {$ex->getMessage()}\n";
    exit(1);
}
// the root element
print "racine=" . $document->documentElement->tagName . "\n";
// the first teacher, found using the selector CSS
$personne = $document->querySelector('enseignant > personne');
print "nom=" . $personne->querySelector('nom')->textContent . "\n";
print "sexe=" . $personne->getAttribute('sexe') . "\n";
print "formation=" . $document->querySelector('etudiant > formation')->textContent . "\n";
// a missing element: querySelector returns null
print "xx existe=" . var_export($personne->querySelector('xx') !== null, true) . "\n";
// all people in the document
foreach ($document->querySelectorAll('personne') as $personne) {
     // the null-safe operator ?-> protects against a missing element
    $prénom = $personne->querySelector('prenom')?->textContent ?? '?';
    $nom = $personne->querySelector('nom')?->textContent ?? '?';
    print "personne : $prénom $nom ({$personne->getAttribute('sexe')})\n";
}
// document modification: the content of the <section> element for the teacher is changed
$section = $document->querySelector('enseignant > section');
$section->textContent = "26";
// the modified document, as text XML
print $document->saveXml($document->querySelector('enseignant')) . "\n";

    Comments

    • line 7: the [XMLDocument] class in the [Dom] namespace;
    • Line 14: The static method [createFromFile] loads the document. Unlike [simplexml_load_file], it throws an exception if an error occurs;
    • line 20: the property [documentElement] is the root element; [tagName] is its name;
    • line 22: the selector CSS [enseignant > personne] refers to an element [personne] that is a direct child of an element [enseignant]. [querySelector] returns the first matching element, or [null] if there are none;
    • line 23: the [textContent] property is the text contained in the element;
    • line 24: the value of an attribute;
    • line 27: a missing element returns [null];
    • line 29: all [personne] elements in the document;
    • Line 31: If the element [prenom] were missing, [querySelector('prenom')] would result in [null]. The null-safe operator [?->] (PHP 8.0) then returns [null] instead of causing an error, and the operator [??] replaces this [null] with ['?'];
    • line 37: the API DOM also allows the document to be modified: here, the text of the [section] element is changed;
    • line 39: [saveXml] returns the text XML from the document, or from one of its elements if it is passed as a parameter.
