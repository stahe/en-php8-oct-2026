    22. Practical Exercise – Version 11

    It is still common for web services to send their response in the form of a XML document rather than a JSON document:

    • the JSON document is smaller, but you need instructions to understand it;
    • the XML document is more verbose but is self-documenting. It is immediately understandable.

    We are modifying the client/server application from version 10 so that the server now sends a XML document in response to its clients. In doing so, we are putting the previous chapter into practice.

    <?php

declare(strict_types=1);

// namespace
namespace Application;

// utility functions for the format XML: the class is neither instantiable nor derivable
final class XmlUtilitaires
{
     // private constructor: the class cannot be instantiated
    private function __construct()
    {
    }

     // returns the XML document from an array [$data]: the root element is named [$racine]
     // The array keys become element names, and the values become their content
    public static function arrayToXml(array $data, string $racine): string
    {
         // an empty XML document (new API DOM from PHP 8.4)
        $document = \Dom\XMLDocument::createEmpty();
         // the document will be indented
        $document->formatOutput = true;
         // the root element and its descendants
        $document->append(self::element($document, $racine, $data));
         // the text XML from the document
        return $document->saveXml();
    }

     // converts the element XML to [<$nom>$valeur</$nom>]
    private static function element(\Dom\XMLDocument $document, string $nom, mixed $valeur): \Dom\Element
    {
        $element = $document->createElement($nom);
        if (is_array($valeur)) {
             // a table: each element of the table becomes a child element (recursive call)
            foreach ($valeur as $clé => $sousValeur) {
                 // the elements of a list (keys 0, 1, 2...) are called [item]
                $element->append(self::element($document, is_int($clé) ? "item" : $clé, $sousValeur));
            }
        } else {
             // a simple value becomes the element’s text (the characters <, >, & are encoded as DOM)
            $element->textContent = match (true) {
                is_bool($valeur) => $valeur ? "true" : "false",
                default => (string) $valeur,
            };
        }
        return $element;
    }
}

    Comments

    • line 9: Like the [Utilitaires] class in version 5, this class has only static methods. It is [final], and its constructor is private: it cannot be derived from or instantiated;
    • line 18: The static method [arrayToXml] returns the document XML from the array [$data] passed as a parameter. The second parameter is the name of the document’s root element;
    • line 21: We use the new API DOM from PHP 8.4, introduced in the previous chapter. The static method [createEmpty] creates an empty XML document. Script PHP 7 used [SimpleXML], which can also generate a document, but not as well: you had to code the special characters in the text yourself using the [htmlspecialchars] function;
    • line 23: the resulting document will be indented, making it more readable;
    • line 25: the document’s root element, created by the [element] method, is added to the document;
    • line 27: the method [saveXml] renders the text XML in the document;
    • line 31: the private method [element] returns the element XML with the name [$nom], representing the value [$valeur];
    • line 33: the [createElement] method of the document creates the element;
    • Lines 34–38: If the value is an array, each of its elements becomes a child element, created by a recursive call to the [element] method. The keys of the array become the names of the child elements. The keys of a list are the integers 0, 1, 2..., which cannot be XML element names: these elements are therefore named [item]. The script PHP 7 referred to them as [i0], [i1], [i2]...;
    • lines 40–45: otherwise, the value becomes the element’s text, assigned to its [textContent] property. The characters [<], [>], and [&] in the text are encoded as DOM ([&lt;], [&gt;], [&amp;]). Booleans are written as [true] and [false]; other values are converted to strings. The expression [match (true)] selects the first branch whose condition is true.

// Sending the response HTTP to the client
// $result: the table to be sent, in the form of the document XML <response>...</response>
// $statusCode: the HTTP status of the response
// $headers: the HTTP headers to be added to the response
// $logger: the application log (null if it could not be created)
// $redis: the Redis client (null if it has not yet been created)
function sendResponse(
    array $result,
    int $statusCode,
    array $headers = [],
    ?Logger $logger = null,
    ?RedisClient $redis = null
): void {
     // the response XML
    $response = new Response(XmlUtilitaires::arrayToXml($result, "réponse"), $statusCode, $headers);
    $response->headers->set("Content-Type", "application/xml; charset=utf-8");
     // sent
    $response->send();
     // logged in JSON, more concise than XML
    $logger?->write(json_encode(
        ["réponse" => $result],
        JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_PRESERVE_ZERO_FRACTION
    ));
     // Closing the connection to the Redis server
    $redis?->disconnect();
}

             // sending the request to the server
            $response = $this->httpClient->request("GET", $this->urlServer, $options);
             // the status, headers, and response body (XML), even in the event of an error (false parameter)
            $statusCode = $response->getStatusCode();
            $headers = $response->getHeaders(false);
            $contenu = $response->getContent(false);
        } catch (ExceptionInterface $ex) {
             // The server could not be reached
            throw new ExceptionImpots("Erreur de communication avec le serveur ({$ex->getMessage()})", 40, $ex);
        }
         // logs
         // print "$contenu\n";
         // the server sends the document XML <response>...</response>
         // the options LIBXML_NOERROR and LIBXML_NOWARNING prevent warnings from PHP if XML is invalid
        $xml = simplexml_load_string($contenu, options: LIBXML_NOERROR | LIBXML_NOWARNING);
        if ($xml === false || $xml->getName() !== "réponse") {
            throw new ExceptionImpots("Réponse du serveur invalide [$contenu]", 41);
        }
         // error?
        if ($statusCode !== 200) {
             // an exception is thrown with a message that is the server’s response, converted to JSON (more concise),
             // supplemented by its status HTTP
            $réponse = json_decode(json_encode($xml, JSON_THROW_ON_ERROR), true, flags: JSON_THROW_ON_ERROR);
            $message = json_encode(
                ["statut HTTP" => $statusCode] + $réponse,
                JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_THROW_ON_ERROR
            );
            throw new ExceptionImpots($message, 42);
        }
         // retrieve the session cookie if it is not yet known
        if ($this->sessionCookie === null) {
            foreach ($headers["set-cookie"] ?? [] as $cookie) {
                if (preg_match('/^PHPSESSID=(.+?);/', $cookie, $champs) === 1) {
                    $this->sessionCookie = "PHPSESSID=$champs[1]";
                }
            }
        }
         // the response is returned: the array [impôt, surcôte, décôte, réduction, taux]
         // In the document XML, all values are text: convert them to their respective types
        return [
            "impôt" => (int) $xml->impôt,
            "surcôte" => (int) $xml->surcôte,
            "décôte" => (int) $xml->décôte,
            "réduction" => (int) $xml->réduction,
            "taux" => (float) $xml->taux,
        ];
    }
}

    Comments

    • line 63: The server’s response is read. It is a XML [<réponse>…</réponse>] document;
    • line 72: the [simplexml_load_string] function parses the received XML document and returns a [SimpleXMLElement] object representing its root element, or [false] if the document is not a valid XML document. By default, the [libxml] library used by [SimpleXML] also reports document errors as PHP warnings: the options [LIBXML_NOERROR] and [LIBXML_NOWARNING] suppress them. They are passed via the argument named [options], which avoids having to write the parameter [class_name] that precedes it in the function signature;
    • line 73: the method [getName] returns the name of the root element, which must be [réponse];
    • Lines 77–85: In the event of an error, the exception message will be the string JSON from the server’s response rather than the received string XML, because the string JSON is more concise. To obtain the associative array for the response XML, we use a classic trick: the function [json_encode] can convert an object [SimpleXMLElement] into JSON, and [json_decode] then converts this JSON into an array. The exception message thus has the same format as in previous versions;
    • lines 97–103: the results array is returned. The child elements of the [réponse] element are accessed as properties of the [$xml] object ([$xml->impôt]). In a XML document, all values are text: unlike JSON, XML does not distinguish between integers, real numbers, and character strings. Each value is therefore converted to the type expected by the [métier] layer using the [(int)] and [(float)] operators. The PHP 7 client returned the values as strings.
